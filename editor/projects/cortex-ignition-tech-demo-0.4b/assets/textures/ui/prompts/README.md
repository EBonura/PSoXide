# Controller prompts

The monochrome PlayStation controller prompts are assembled from
Kenney's **Input Prompts Pixel 16x** and **Input Prompts** packs and used under
their CC0 1.0 license. The set includes the four face buttons, L1/L2/R1/R2,
L3/R3, Start, Select, and neutral/directional/pressed D-pad variants.

Most prompts occupy one 16x16 glyph cell. Start and Select retain their labels
and silhouettes in wider 40x16 and 44x16 textures; authored UI image rectangles
can use those native dimensions instead of squeezing them into square cells.

- Pixel source: https://kenney.nl/assets/input-prompts-pixel
- Full source: https://kenney.nl/assets/input-prompts
- License: https://creativecommons.org/publicdomain/zero/1.0/

Each PNG is retained as the editable source; the matching `.psxt` is the
4-bpp, transparent-zero runtime texture used by PSoXide.
