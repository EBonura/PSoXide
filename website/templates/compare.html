How it was measured

All four emulators ran headless on one Apple M3 Max MacBook Pro (14 cores, 36 GB, macOS 26.6.2, on AC power). Nothing opened a window or played audio, and each rendered in software at native resolution. Every game started from power-on with the same pad schedule PSoXide's compatibility runs use, and captured frames confirmed each emulator had reached the same part of the game before the measuring window opened.

    {% if config.extra.show_speed %}
  • Frames per CPU-second: emulated frames in a 1200-frame window (600 for Resident Evil 2) at unlimited speed, divided by the process's user plus system CPU time. The calculation includes CPU time from every thread, including rendering threads.
    • {% endif %}
  • CPU and memory at 1×: each emulator paced to the console's field rate (59.83 Hz NTSC, 49.76 Hz PAL). CPU is CPU time over wall time; memory is the median physical footprint, sampled every 0.25 s.
    • {% if config.extra.show_speed %}
  • Real-time headroom: frames per CPU-second divided by {{ bench.field_hz }}.
    • {% endif %}
  • Versions: PSoXide {% for e in history %}{{ e.build }}{% if not loop.last %}, {% endif %}{% endfor %} (release profile), DuckStation 459a6fc, Beetle PSX HW 0.9.44.1 (ee042b7) through a minimal libretro frontend, PCSX-Redux 1b7a4f1d in -cli mode.

Caveats

  • Memory is measured without a frontend for every emulator, so real use costs more once a window, a GPU and audio are added. DuckStation's number includes about 360 MB of graphics allocations its regression runner keeps open.
  • Disc data read on demand sits in the OS file cache, outside the process, for every emulator that streams. None of the footprints count it.
  • Boot timing differs slightly between a BIOS boot and PSoXide's HLE boot, so Tekken 3 picks a different opponent and stage on each emulator. The other games reach the same scene with small differences.
    • {% if config.extra.show_speed %}
  • PCSX-Redux paces itself to real time while CD audio streams, so in Tekken 3, WipEout 2097 and Resident Evil 2 its speed was measured at 1×, not unlimited.
    • {% endif %}
  • Beetle's recompiler couldn't reserve its fast memory map on macOS and warned it would run slower. It deadlocked once in 30 runs; that run was repeated.
  • Standalone Mednafen has no windowless mode, so Beetle PSX, the libretro fork of its PS1 core, stands in for it.

The raw per-run CSV and the harness are kept with the benchmark. This page reads data/emu-bench.json, generated from the harness's summary CSV by site import-emu-bench (tools/xtask).
