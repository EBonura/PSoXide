Rust for the original PlayStation

Development tools for the original PlayStation.

PSoXide is a Rust SDK, engine, scene editor and emulator for PS1 software. Build for the console, then test and debug on desktop or in the browser. The emulator uses its own kernel and requires no BIOS file.

The toolkit

Write Rust programs with the SDK or build scenes in the editor. Create a disc image, test it in the emulator and run it on a PlayStation that supports burned CD-Rs.

SDK

Rust APIs for graphics, audio, controllers, CDs and memory cards, plus fixed-point maths and disc-building tools.

EBonura/PSoXide

Editor and engine

Build and test scenes with geometry, materials, animation, audio and UI, then export them as a PS1 disc image.

EBonura/PSoXide-editor

Emulator

For playing, debugging and profiling, on desktop and in the browser. Its own kernel boots discs.
