The toolkit

Built for fast, testable iteration

Write Rust programs with the SDK or build scenes in the editor. Create a disc image, inspect it in the emulator and test it on the console. Command-line workflows and debugging tools make each step repeatable.

Build, run, inspect and test →

SDK

Rust crates for graphics, the GTE geometry coprocessor, sound, FMV, controllers, CDs and memory cards, plus tools that build discs and convert audio.

EBonura/PSoXide

Editor and engine

Build and test scenes with geometry, materials, animation, audio and UI, then export them as a PS1 disc image.

EBonura/PSoXide-editor

Emulator

For playing, debugging and profiling, on desktop and in the browser. Its own kernel boots discs.

EBonura/PSoXide-emulator

Demo disc

A collection of games and examples with a launch menu, available for the console and browser player. Burned discs require a modchipped console or another homebrew boot method.

EBonura/PSoXide-demo-disc

PSoXide does not endorse modchipping or provide installation help. Console modifications can permanently damage or brick hardware and are at your own risk. Read the hardware warning.
