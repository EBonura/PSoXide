Rust for the original PlayStation

Making impossible PS1 ports possible.

An SDK, an engine and editor, and an emulator, all built to get more out of a 33 MHz console with 2 MB of RAM. The emulator boots games on its own kernel, with no BIOS.

The toolkit

Write bare-metal Rust against the hardware, or build a game in the editor and cook it to a disc. Test it in the emulator, then burn it and run it on a console.

SDK

Typed Rust over the GPU, GTE, SPU, pads, CD and memory cards, with fixed-point maths and a disc packer.

EBonura/PSoXide

Editor and engine

Scenes, BSP geometry, materials, animation, audio and UI, cooked into a PS1 disc and playtested in place.

EBonura/PSoXide-editor

Emulator

For playing, debugging and profiling, on desktop and in the browser. Its own kernel boots discs.

EBonura/PSoXide-emulator

Demo disc

One CD-R that boots on a real PlayStation and chain-loads the programs burned alongside it.
